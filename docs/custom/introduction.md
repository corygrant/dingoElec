# Custom Devices

dingoFW and dingoConfig can be used on hardware designed by others.

## Adding Your Own Device

See [Customization](../dingofw/custom.md) for how to add a new board to dingoFW and dingoConfig.

If you've built a device that uses dingoFW, let me know on Discord. 

To include your custom board in the main dingoConfig and dingoFW repos a test board must be donated for current and future testing and validation.
